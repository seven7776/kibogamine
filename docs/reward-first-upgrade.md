# 希望之峰：先让黑白熊好玩

## [文档] 本轮目标与已确认的顺序

用户确认：先把黑白熊做得有吸引力，让源远愿意玩；以后逐步加强学习检验和挑战难度。本轮完成第一阶段，保留现有学习积分规则。

用户反馈：源远对比角色原图后认为牙齿细节不像，玩了一小会儿就觉得互动少。这个反馈是用户提供的使用观察，不等于开发端的实机测评。

## [文档] 本轮实现

- 黑白熊常态笑嘴改成沿脸颊弯曲的连续白色牙带，增加细牙缝和嘴角轮廓，重画红眼折线与双瓣口鼻。依据用户提供的角色设定图修整，没有使用官方 3D 模型。
- 修正耳朵被裁切、肚皮与身体相交、脚部遮挡；修正切换动画时姿势残留。
- 黑白熊房间增加「去闯关」，进入独立的游乐地图。六关分别引入换道、跳栏、移动路障、加速带及组合挑战；每关约 35—55 秒。
- 平板左右按钮换道、跳跃按钮起跳；赛道支持左右/向上滑动，电脑支持方向键与空格。粉色高墙要绕开，金色矮栏可跳过。
- 三颗爱心、倒计时、星星收集、终点旗门、暂停与免费重试。切到后台自动暂停，返回后手动继续。
- 通关 1 星、达到收集目标再得 1 星、同时无碰撞再得 1 星。记录各关最高星级与最多收集数，关卡星不会重复累加。首次提升星级增加少量羁绊和心情，不发放学习奖章。
- 关卡星逐步解锁后续场景与三种脚步特效；经典脚步默认开放。无随机抽奖、付费入口或失败惩罚。
- 修复喂食等互动刚开始就被页面重绘打断的问题；离开页面释放旧 3D 场景，隐藏的漫游熊停止渲染。
- 游戏进度保存在现有备份数据的 arcade 字段中。旧用户自动补充该字段，课表、学习记录和原有奖章不迁移、不重置。

## [实测] 电脑端验证

- 用 Edge 的实际 WebGL 渲染检查房间、地图、赛道、九款皮肤及现有姿态。
- 在独立测试浏览器中模拟操作，六关均完成通关；另验证了不避让时碰撞失败和免费重试入口。
- 检查星级计算、重复挑战不重复奖励、锁定关卡、特效解锁及刷新后恢复。
- 暂停后时间与状态不继续变化；反复进出场景后动画循环数量回到基线。
- 检查手机窄屏和平板横竖屏布局，没有横向溢出。
- 对比测试前后的学习记录、课表、打卡数据和学习奖章，闯关没有改变这些内容。

## [待验] 实际体验边界

- 没有连接源远的华为平板，未验证该机的帧率、温度、浏览器内核和 APK 内的真实触摸体验。
- 自动操作通关只能验证机制可以运行，不能证明对源远来说好玩，也不能代表难度合适。
- 角色已按参考修整，是否达到源远认可的还原度仍待本人对比。当前仍是程序化卡通模型，服装细节和表情丰富度有限。
- 做题、作业照片、音视频、跟读的严格验收留到后续阶段；本轮没有增加学习检验门槛。

## [推断] 下一轮最有用的反馈

让源远先自由尝试，观察他能否独立理解操作、是否愿意主动重玩，以及具体在哪一关或哪个动作失去兴趣。以这些实际反应决定下一轮玩法和还原细节，避免仅根据功能数量判断成功。

## 使用入口

原网址：https://seven7776.github.io/kibogamine/#/arcade

在原 App 中进入「黑白熊 → 去闯关」。联网重新打开后检查更新；若仍看到旧页面，使用 App 设置中的更新按钮。不要清除浏览器数据或卸载来强制刷新。现有 APK 的网页入口不变，本轮网页内容升级不要求重新打包。
