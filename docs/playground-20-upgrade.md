# 希望之峰：20关乐园升级（v42）

[文档] 黑白熊现在朝赛道前方奔跑，操作者看到背面；抵达终点后转身庆祝。每关首次通关增加一项成长奖励，自动用于下一局和乐园预览，重复挑战不会重复发奖。
