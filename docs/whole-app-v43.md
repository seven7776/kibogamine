# 希望之峰 v43：全 App 优化交付说明

[文档] 本轮覆盖首页、跟课学习、课表、每日打卡、黑白熊成长展示和设置，并增加闯关的倒退、停止与加速控制。

## 已实现

| 位置 | 改动 |
| --- | --- |
| 首页 | 主科卡片直接进入对应学科；增加“接着上次学”；按时间汇总校内课程和课外班 |
| 学习 | 课文内可保存练习文字、用时和照片/音频/视频；可回看记录；修复无效课文链接报错和完成按钮状态 |
| 每日打卡 | 每项可保存练习过程；提供记录本查看往日记录；当天尚未打卡时，延续昨天的连续天数 |
| 课表 | 新增和编辑使用同一表单，可改星期；检查起止时间以及同日课外班时间重叠 |
| 黑白熊成长 | 成长装备可点击预览，支持转身看背面；预览显示实际模型和拖尾、星屑等效果，不改变解锁进度 |
| 乐园控制 | 左右移动、跳跃之外，新增倒退、停止、前进、加速四键；停止后用前进恢复，倒退不会越过起点 |
| 设置 | 检查更新不再先删除离线缓存；进度导入先校验再确认；练习记录与附件可单独导出、合并恢复 |

[文档] 倒退重走时，已经收集的星星不会重复出现或计奖。赛道进度按位置计算，倒退会增加剩余路程；停止会冻结行进，不能靠等待自动通关。计分栏改为数值变化时更新；落地前最后约0.15秒按下跳跃，可在落地后接上下一跳。

[文档] 练习附件仅保存在当前设备，未接入云端或自动评分。支持选择系统已拍摄、录好的照片/音频/视频；每条最多3个附件，每个20MB以内、总计40MB以内。保存附件不会自动增加奖章。现阶段仍保留自主勾选打卡，学习检验没有突然加严。

## 验证情况

- [实测] 单元测试：日期处理、连续打卡、课外班时间及冲突、备份结构校验、游戏进退边界、星级和旧进度兼容。
- [实测] 桌面浏览器：20关重新自动通关，失败及重试、奖励保存、重复进入后的动画清理。
- [实测] 首页直达学科、继续上次课文、当天课外班展示；课外班改星期、拒绝倒置时间与冲突时段。
- [实测] 练习文字和照片保存、重开、历史回看；附件备份下载并在全新浏览器存储中恢复；损坏进度备份未覆盖现有数据。
- [实测] 新控制键改变实际赛道位置；停止冻结赛道，倒退重走不重复收星，加速确实更快；落地前跳跃输入能接续。
- [实测] 六个主要页面在模拟平板/手机尺寸下无横向页面溢出；离线缓存可重开，离线状态下检查更新不会清缓存。
- [待验] 真实华为平板帧率、触控手感、音视频格式兼容，以及源远对难度和耐玩程度的评价。
- [待验] 江苏南通学校实际使用教材的逐页核对、未完成课程内容补齐，以及后续做题/跟读/家长核验与奖章的联动。本轮没有把这些标记为已完成。

## 使用与备份

[文档] 原安装版进入“设置 → 检查更新”，无需卸载。入口：https://seven7776.github.io/kibogamine/ 。

[文档] “导出备份（JSON）”保存奖章、课表、学习、打卡和游戏进度；“导出练习记录与附件”保存练习文字与媒体。更换设备前分别导出。已有本地课本照片不在这两份备份里，请继续保留原图。“重置进度”保留练习附件与本地课本。
