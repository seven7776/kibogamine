## 3. 页面结构（底部5Tab，横屏自动切左侧导航）
1. **首页**：欢迎卡（连续希望天数+今日进度圆环）、今日课程（从课表自动带出，点卡直达学科页）、积分/专注/已学三格、今日任务清单
2. **学习**：语文(部编版)/数学(苏教版)/英语(译林版) 五上全学期单元框架；每课一页：学习重点→预习任务→词语/单词/知识点→练习→打卡→小结。v1 填满三科第一单元，其余骨架
3. **课表**：6节×5天网格可编辑（点格改课）+ 课外班区（名称/星期/起止时间，可增删）
4. **打卡**：钢琴/吉他/课外阅读/做家务/运动 5 默认项，可自定义添加；连续天数+本周星星墙
5. **黑白熊**：萌宠房间 + 全局溜达

## 4. 萌宠系统（核心差异化）
- 形象：代码手绘像素黑白熊（参照官方 DOT PATTERN），canvas 渲染，image-rendering: pixelated
- 动作帧：站立眨眼 / 走路2帧 / 坐 / 睡觉(Z) / 爆笑 / 捂嘴偷笑(挠痒) / 生气 / 干饭 / 喝水 / 背影(翻身)
- 全局溜达：随机游走、坐下、打盹；点击抬头互动
- 状态四条：饱腹/口渴/心情/精力，随时间衰减；过低触发生气表情+弹丸式台词
- 互动（花积分）：喂水/喂饭/吃零食/挠痒痒/翻身/换皮肤/哄睡觉
- 皮肤（官方图鉴）：经典款 / 西装红领带 / 反色 / 金色 / 赛博 / 虚拟像素绿 / 草裙尤克里里 / 泳圈 / 牛仔，各有解锁条件
- 等级：羁绊 Lv.1"刚认识"起步，互动+打卡升级，解锁动作/皮肤

## 5. 积分 = 黑白熊奖章（官方设定货币）
- 赚：学习一课 +20、打卡一项 +10、连续7天额外 +30、每日任务全清 +20
- 花：喂饭 -5 / 喂水 -3 / 零食 -10 / 挠痒 -5 / 翻身 -5 / 哄睡 -8 / 皮肤 -50 起
- 先赚后花，余额不足按钮置灰
